# Misgeret 1.0.0

The first public release of Misgeret: a free, open-source, local-first financial desktop application for Israeli households.

## Highlights

- No registration, account, Google sign-in, trial, subscription, or payment.
- Windows x64, macOS Apple Silicon, macOS Intel, and Linux x64 packages.
- Local per-profile SQLite databases, local backups, and CSV export.
- Connections for ten Israeli banks, four credit-card providers, and two benefit clubs.
- Monthly, yearly, overview, recurring-pattern, forecast, financial-health, planning, and net-worth views.
- Multi-institution reconciliation, deterministic categorization, and user-controlled recurring-item verdicts.
- AES-256-GCM protection for institution login fields with an OS-protected master key.
- Aggregate SHA-256 checksums for every release artifact.

## Important notes

- Windows and macOS builds are not yet code-signed or notarized. SmartScreen or Gatekeeper may warn on first launch.
- Misgeret is not an Open Banking provider. Institution website changes can temporarily break synchronization.
- The local transaction database is not encrypted at rest. Use full-disk encryption and a protected OS account.
- Windows updates automatically through GitHub Releases. macOS and Linux updates are manual.

See the [installation and security guidance](../../README.md) before connecting a real institution.
