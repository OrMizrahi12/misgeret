# Support

Misgeret is a community-maintained project without a paid support desk or service-level agreement.

## Questions and troubleshooting

Use the [Q&A discussion category](https://github.com/OrMizrahi12/misgeret/discussions/categories/q-a) for installation, development, and usage questions. Search existing discussions first and include the Misgeret version and operating system.

Never post credentials, real transactions, balances, database files, exports, backups, logs, encryption keys, browser profiles, or identifying screenshots.

## Reproducible bugs

Use the [bug report form](https://github.com/OrMizrahi12/misgeret/issues/new?template=bug_report.yml) when you can provide clear reproduction steps using synthetic or fully redacted data.

## Feature ideas

Use [Ideas](https://github.com/OrMizrahi12/misgeret/discussions/categories/ideas) for early proposals. Once a proposal has a focused scope and acceptance criteria, it can become a feature issue.

## Security vulnerabilities

Do not open a public issue or discussion. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
